# Premium Portfolio

A production-ready personal portfolio for a Senior Full Stack Developer, AI Engineer, and Automation Architect.

## Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Dark and light mode
- SEO metadata

## Local Development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production

```bash
pnpm build
pnpm start
```

The project is ready for Vercel deployment. Import the repository, keep the default Next.js settings, and deploy.
